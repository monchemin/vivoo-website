# Vivoo — Page module : Campagnes multicanal
### `/produit/campagnes`

---

## Une campagne, cinq canaux, zéro copier-coller

Composez un message une seule fois et envoyez-le sur WhatsApp, Messenger, Instagram, SMS et courriel depuis la même interface — sans reproduire la même campagne cinq fois dans cinq outils différents.

---

## Ce que le module permet

**Envoi simultané multicanal.** Une même campagne rejoint votre audience sur les canaux où elle se trouve réellement, sans dupliquer le travail de rédaction ni de configuration.

**Segmentation ciblée.** Une campagne ne part jamais à toute votre audience par défaut — vous choisissez le segment précis à qui elle s'adresse, selon le comportement ou l'historique de chaque profil.

**Suivi de l'engagement généré.** Chaque campagne montre ce qu'elle a produit — ouvertures, réponses, actions concrètes — pour savoir ce qui fonctionne avant d'en lancer une autre.

---

## Questions fréquentes

**Puis-je envoyer une campagne à un segment précis de mon audience seulement ?**
Oui. Vous choisissez le segment ciblé avant l'envoi — pas besoin de rejoindre toute votre audience à chaque campagne.

**Quels canaux sont pris en charge pour les campagnes ?**
WhatsApp, Messenger, Instagram, SMS et courriel — les cinq canaux gérés par Vivoo, depuis une seule interface.
