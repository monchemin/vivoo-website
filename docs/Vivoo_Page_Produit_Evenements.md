# Vivoo — Page module : Gestion d'événements
### `/produit/evenements`

---

## Un événement, une liste d'invités, aucun suivi manuel

Que ce soit un lancement, une formation ou une soirée portes ouvertes, le module d'événements de Vivoo gère l'inscription et le suivi sans feuille de calcul ni relance manuelle.

---

## Ce que le module permet

**Inscription simplifiée.** Un lien ou un code QR dédié à l'événement suffit — l'invité s'inscrit directement, sans formulaire papier ni échange de courriels.

**Suivi dans l'audience unifiée.** Chaque inscrit rejoint votre audience captée, avec l'événement comme point d'origine — utile pour cibler des suivis pertinents par la suite.

**Communications automatiques.** Des messages peuvent être programmés avant l'événement (rappel) et après (remerciement, suivi), sans intervention manuelle une fois configurés.

---

## Questions fréquentes

**Comment les invités s'inscrivent-ils à un événement ?**
Par un lien ou un code QR dédié à l'événement, qui les mène directement à une inscription — sans formulaire papier.

**Puis-je envoyer un rappel automatique avant l'événement ?**
Oui, via le module d'automatisation — un rappel programmé peut être envoyé à tous les inscrits avant la date de l'événement.
