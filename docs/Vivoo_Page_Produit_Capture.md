# Vivoo — Page module : Capture d'audience
### `/produit/capture`

---

## Votre prochain client commence par un code QR

Le module de capture de Vivoo transforme un simple scan en profil d'audience — sans application à installer, sans formulaire à remplir sur papier, sans délai entre le premier contact et son inscription.

---

## Ce que le module permet

**Capture sans friction.** Un client scanne le code QR avec l'appareil photo de son téléphone et atterrit directement dans une conversation WhatsApp ou sur une page de capture — aucune application à télécharger.

**Plusieurs points de capture.** Le même mécanisme fonctionne en boutique, sur une facture, à un événement ou intégré à une page web — chaque contexte peut avoir son propre code, pour savoir d'où vient chaque profil. Le lien qui accompagne chaque code se personnalise aussi, avec une adresse facile à retenir et à partager plutôt qu'une suite de caractères générée au hasard.

**Ajout automatique à l'audience.** Dès qu'un profil est capté, il rejoint votre audience unifiée — prêt à recevoir une campagne, un scénario d'automatisation, ou simplement à être consulté dans votre historique client.

---

## Questions fréquentes

**Le client doit-il installer une application pour être capté ?**
Non. Le scan mène directement à une conversation sur un canal qu'il utilise déjà (WhatsApp, par exemple), ou à une page de capture dans son navigateur.

**Où puis-je afficher mon code QR Vivoo ?**
Partout où un client vous voit physiquement ou virtuellement : en boutique, sur une facture, à un événement, ou intégré à votre site web.

**Que se passe-t-il après qu'un client scanne le code ?**
Son profil est ajouté à votre audience, prêt à être ciblé par une campagne ou à entrer dans un scénario d'automatisation, selon ce que vous avez configuré.
